# 무술 격투 3D — Martial Arts Fighter 3D

Three.js로 만든 브라우저 3D 격투 게임. 태권도/가라테/쿵푸 유파를 골라
1인용(vs CPU) 또는 2인용(분할 화면) 대전을 즐길 수 있습니다.

**▶ 플레이:** https://hanjinwoo04221.github.io/3d-martial-arts-fighter/

## 특징

- Three.js 절차적 3D 휴머노이드 캐릭터, 유파별 필살기
- 방향 입력에 따라 자동 전환되는 8종 타격기(잽/스트레이트/엘보/보디블로우/
  앞차기/돌려차기/백스핀킥/스윕) + 사이드스텝/백대시/대시 회피 동작
- 캐릭터별 3인칭(오버더숄더) 카메라 — 2인용은 좌우 분할 화면
- 일부 타격 애니메이션은 **Blender MCP**로 실제 애니메이션 커브 편집기(F-curve,
  베지어 이징)를 통해 제작한 뒤 게임에 베이크되어 재생됩니다 (`blender/fight_curves.json`)

## 로컬 실행

정적 파일이라 별도 빌드가 필요 없습니다. 로컬 서버로 열면 됩니다:

```bash
python -m http.server 8080
# http://localhost:8080 접속
```
